# Портфолио Ярослава Белоглазова

Сайт: https://zef1r34.github.io/

Интерактивный рабочий стол в стиле Windows 7: перетаскивание ярлыков, Проводник с меню файлов, свойства проектов, окно для работодателя, Internet Explorer, Paint и диспетчер задач. Также доступны Блокнот, PDF-резюме, пошаговый помощник баг-репортов, калькулятор по данным слайсера и 3D-просмотрщик STL, OBJ, 3MF и STEP/STP. В панели управления есть звук, дата, обои и шуточная диагностика сети.

Основная оболочка и мини-приложения встроены в index.html. Трёхмерный просмотрщик использует отдельные JS/WASM-файлы из этого же репозитория. Редактируемые исходники — в source.zip.

Для локального просмотра распакуйте исходники и выполните node server.mjs. Для обновления сборки выполните node build.mjs и загрузите все восемь файлов из dist в корень этого репозитория. 3D-runtime и CAD-модуль загружаются отдельно по необходимости.

Создано с помощью ИИ под руководством Ярослава. Используется 7.css (MIT); лицензия и сведения о Windows-ресурсах включены в архив исходников.
