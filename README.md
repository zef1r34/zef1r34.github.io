# Портфолио Ярослава Белоглазова

Сайт: https://zef1r34.github.io/

Интерактивный рабочий стол в стиле Windows 7: Проводник, Блокнот, резюме, контакты, конструктор баг-репортов и калькулятор затрат на 3D-печать.

В index.html находится готовая самодостаточная сборка со встроенными ресурсами. Редактируемые исходники — в source.zip.

Для локального просмотра распакуйте исходники и выполните node server.mjs. Для обновления сборки выполните node build.mjs и загрузите содержимое dist в корень этого репозитория.

Создано с помощью ИИ под руководством Ярослава. Используется 7.css (MIT); лицензия и сведения о Windows-ресурсах включены в архив исходников.
